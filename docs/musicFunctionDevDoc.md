## 一、给 Code Agent 的提示词

你可以直接把下面这段内容复制给 Code Agent（如 Cursor、Claude Code、Windsurf 等），它包含了完整的接口文档、功能需求和技术约束。

---

### 📋 提示词正文

````markdown
# 任务：为个人网站开发一个「我喜欢的音乐」播放功能

## 一、背景

我要在自己的个人网站上增加一个音乐播放模块，展示并播放我收藏的歌曲。
音乐数据来源是免费的 GD音乐台 API（https://music-api.gdstudio.xyz/api.php），
该 API 无需登录、无需 API Key，返回 JSON 数据。

## 二、API 接口文档（已实测可用）

### 基础信息
- 基础 URL：`https://music-api.gdstudio.xyz/api.php`
- 请求方式：GET
- 返回格式：JSON
- 音源参数 `source` 建议使用：`netease`（网易云，最稳定）、`kuwo`（酷我）、`joox`
- 中文参数必须进行 URL 编码（如 "起风了" → `%E8%B5%B7%E9%A3%8E%E4%BA%86`）

### 接口 1：搜索音乐
```
GET /api.php?types=search&source=netease&name={关键词}
```
返回示例（数组，每项代表一首歌）：
```json
[{
  "id": "1330348068",
  "name": "起风了",
  "artist": ["冯沁苑(买辣椒也用券)"],
  "album": "起风了",
  "pic_id": "109951163699673355",
  "url_id": "1330348068",
  "lyric_id": "1330348068",
  "source": "netease"
}]
```
关键字段：`url_id`（获取播放链接用）、`pic_id`（获取封面用）、`lyric_id`（获取歌词用）。

### 接口 2：获取播放链接
```
GET /api.php?types=url&source=netease&id={url_id}&br=320
```
`br` 可选：128 / 192 / 320 / 999（999 为无损，可能失败）。
返回示例：
```json
{"url":"https://m701.music.126.net/.../xxx.mp3","br":320,"size":13037236}
```
返回的 `url` 可直接放入 `<audio>` 标签播放，实测可用。

### 接口 3：获取封面图
```
GET /api.php?types=pic&source=netease&id={pic_id}&size=300
```
`size` 可选 300 / 500。返回：`{"url":"https://p1.music.126.net/.../xxx.jpg"}`

### 接口 4：获取歌词
```
GET /api.php?types=lyric&source=netease&id={lyric_id}
```
返回：`{"lyric":"[00:00.00] 作词...\n...","tlyric":"翻译歌词（可能为空）"}`

## 三、功能需求

1. **歌曲列表展示**：从配置文件（或写死的数据）读取我喜欢的歌曲列表，每条包含歌曲名、歌手、音源、歌曲 ID。页面加载时展示这个列表。
2. **点击播放**：点击某首歌时，调用「获取播放链接」接口，拿到 URL 后用 `<audio>` 播放。播放中高亮当前歌曲。
3. **播放器控件**：播放/暂停、上一首/下一首、进度条、音量、当前播放时间。
4. **封面与歌词**：播放时异步获取封面图和歌词，封面显示在播放器旁，歌词可滚动展示（LRC 格式解析）。
5. **搜索功能（可选）**：提供搜索框，调用搜索接口，结果可点击加入播放列表或直接播放。
6. **缓存**：将已获取的播放链接、封面、歌词缓存到内存或 localStorage，避免重复请求。
7. **错误处理**：接口失败时给出友好提示（如「暂时无法获取，请稍后重试」），并自动尝试备用音源（netease → kuwo → joox）。

## 四、技术约束（非常重要）

### 1. 跨域问题（CORS）
浏览器前端**直接调用** GD音乐台 API 会遇到 CORS 限制。
必须通过一层**后端代理**转发请求。推荐方案（任选其一）：
- **Cloudflare Pages Functions**（推荐，参考开源项目 Solara）
- Vercel Serverless Functions
- 自己的服务器（Nginx 反向代理 / PHP / Python Flask 等）

前端所有请求都指向自己的代理地址，由代理转发到 `https://music-api.gdstudio.xyz/api.php`。
注意：音频文件的 URL 也可能有跨域问题，如需 `<audio>` 跨域播放，代理层需设置正确的 `Access-Control-Allow-Origin` 响应头。

### 2. 频率限制
该 API 官方限制：**5 分钟内不超过 60 次请求**。
多人同时访问很容易触发限流。请务必：
- 对搜索结果、播放链接、封面、歌词做缓存
- 用户快速切歌时做防抖/节流
- 不要预加载整个列表的所有歌曲链接（按需加载）

### 3. 音源可用性
目前稳定音源：`netease`、`kuwo`、`joox`。
国外音源（Tidal、Qobuz 等）基本返回空。默认使用 `netease`。

### 4. 兼容性
- 使用原生 HTML/CSS/JS 或轻量框架均可，不引入重型依赖
- 移动端适配（响应式）
- 现代浏览器（Chrome / Edge / Safari / Firefox）

## 五、交付物

1. 前端页面（含播放器 UI、歌曲列表、封面、歌词区域）
2. 后端代理脚本（根据我选的部署方式）
3. 一份简短的 README，说明如何部署、如何添加/修改歌曲列表

## 六、注意事项

- 该 API 仅供个人学习/非盈利使用，**禁止商用**
- 页面需注明数据来源于「GD音乐台 (music.gdstudio.xyz)」
- 请勿高频请求，做好缓存与节流
````

### ⚠️ 额外风险提示

1. **个人网站公开访问仍有风险**：即使标注「个人学习」，若网站公开可访问且音乐可完整播放，仍可能被版权方视为侵权。建议：
   - 不公开推广
   - 不提供下载按钮
   - 如收到投诉，立即下线相关内容

2. **不要存储音频文件**：只做「实时获取 + 流式播放」，不在服务器保存任何 mp3 文件，降低风险。

3. **API 提供方的条款**：GD音乐台明确禁止商用，若你的网站未来有广告或盈利行为，需立即停止使用该 API。

4. **备用方案**：如果担心版权风险，可以考虑改用 **Internet Archive** 的公共领域音乐，或 **Audius** 上的原创作品，这些在版权上更安全。
