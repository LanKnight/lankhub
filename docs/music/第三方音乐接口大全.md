## 1. GD Studio Music API（用户已用的这个，完整文档）

**Base URL**：`https://music-api.gdstudio.xyz/api.php`
**主站**：https://music.gdstudio.xyz/
**协议**：CC BY-NC 4.0 · 需注明出处 "GD音乐台(music.gdstudio.xyz)"
**频率限制**：5 分钟内不超过 50 次请求
**动态可用源**（文档 2026-09-16 更新）：`netease`、`joox`、`bilibili`（`tencent`/`kuwo` 等时好时坏）
**音质档位**：`128` / `192` / `320` / `740`（16bit 无损）/ `999`（24bit 无损，网易云常回 948）

### 1.1 搜索

```http
GET https://music-api.gdstudio.xyz/api.php?types=search&source=netease&name=周杰伦&count=20&pages=1
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `types` | ✅ | 固定 `search` |
| `source` | ❌ | 音乐源，默认 `netease`；可选 `tencent`/`kuwo`/`joox`/`bilibili` 等；**高级用法**：加 `_album` 后缀（如 `netease_album`）获取专辑曲目列表 |
| `name` | ✅ | 关键词：歌名 / 歌手 / 专辑 |
| `count` | ❌ | 每页条数，默认 20 |
| `pages` | ❌ | 页码，默认 1 |

返回字段：`id`(track_id)、`name`、`artist`(数组)、`album`、`pic_id`、`lyric_id`、`source`。

### 1.2 获取播放地址

```http
GET https://music-api.gdstudio.xyz/api.php?types=url&source=netease&id=5257138&br=320
```

返回：`url`（音乐直链）、`br`（实际音质）、`size`（KB）。

### 1.3 专辑封面 / 歌词

```http
# 封面（id 用搜索返回的 pic_id）
GET https://music-api.gdstudio.xyz/api.php?types=pic&source=netease&id=109951165671182684&size=500

# 歌词（id 用 lyric_id，通常与曲目 id 相同）
GET https://music-api.gdstudio.xyz/api.php?types=lyric&source=netease&id=5257138
```

歌词返回 `lyric`（LRC 原文）+ `tlyric`（中文翻译，可能为空）。

### 1.4 周杰伦实测结果（2026-11-22）

```bash
# 搜索周杰伦（netease 源）—— 多为翻唱/现场版
curl -G "https://music-api.gdstudio.xyz/api.php" \
  --data-urlencode "types=search" --data-urlencode "source=netease" \
  --data-urlencode "name=周杰伦" --data-urlencode "count=3"
```
实测返回：想你就写信 (Live)、屋顶、布拉格广场……（原版基本没有）

```bash
# 搜索周杰伦（joox 源）—— 原版专辑曲！
curl -G "https://music-api.gdstudio.xyz/api.php" \
  --data-urlencode "types=search" --data-urlencode "source=joox" \
  --data-urlencode "name=周杰伦" --data-urlencode "count=5"
```
实测返回（繁体原版）：**以父之名 / 最长的电影 / 搁浅 / 晴天**（专辑《葉惠美》《我很忙》《七里香》）

> ⚠️ 注意：实测 joox 源的 `types=url` 返回空链接（`{"url":"","br":-1}`），即**能搜到但放不出来**；netease 源的老歌（如"屋顶" id=5257138）可以正常拿到 320kbps 直链。所以本接口更适合"搜元数据 + netease 源播放"。要拿周杰伦原版播放地址，请用第 3 节 tang 接口。

## 2. TuneHub API（统一聚合，自动换源）

**官方文档**：https://api.tunefree.fun/ 或 https://music-dl.sayqz.com/
**项目介绍**：https://niege.app/t/topic/105
**平台标识** `source`：`netease`（网易云）、`kuwo`（酷我）、`qq`（QQ音乐）
**特色**：**自动换源**（变灰/VIP 时按 `kuwo → netease → qq` 优先级自动找同名歌，返回 302，响应头带 `X-Source-Switch`）；聚合搜索一次并发查所有平台并去重。
**音质参数** `br`：`128k` / `320k` / `flac`(~1000kbps) / `flac24bit`(Hi-Res)

> ⚠️ **实测状态**：`api.tunefree.fun` 证书已过期且返回 403 人机验证拦截页；`music-dl.sayqz.com` 当前网络环境连不上（CONNECT 502）。项目文档完整、设计优秀，但公共实例目前不可用。建议按其文档**自行部署**（GitHub 搜 TuneHub）或过段时间重试。

### 2.1 接口一览（Base URL: `https://music-dl.sayqz.com`）

```http
# 1) 歌曲基本信息
GET /api/?source=netease&id=186016&type=info

# 2) 播放直链（302 跳转到音频文件，支持自动换源）
GET /api/?source=netease&id=186016&type=url&br=flac

# 3) 专辑封面（302 跳转）
GET /api/?source=netease&id=186016&type=pic

# 4) LRC 歌词（纯文本）
GET /api/?source=netease&id=186016&type=lrc

# 5) 单平台搜索
GET /api/?source=netease&type=search&keyword=周杰伦&limit=20

# 6) 聚合搜索（一次搜遍所有平台，自动去重）—— 找周杰伦首选
GET /api/?type=aggregateSearch&keyword=周杰伦

# 7) 歌单详情
GET /api/?source=netease&id=19723756&type=playlist

# 8) 排行榜列表
GET /api/?source=netease&type=toplists

# 9) 排行榜歌曲（id 用排行榜 ID，如 26）
GET /api/?source=qq&id=26&type=toplist

# 10) 健康检查
GET /health
```

`info` 返回示例：
```json
{
  "code": 200, "message": "success",
  "data": {
    "name": "晴天", "artist": "周杰伦", "album": "叶惠美",
    "url": "https://music-dl.sayqz.com/api/?source=netease&id=186016&type=url",
    "pic": "https://music-dl.sayqz.com/api/?source=netease&id=186016&type=pic",
    "lrc": "https://music-dl.sayqz.com/api/?source=netease&id=186016&type=lrc"
  }
}
```

## 3. Tang QQ音乐开放接口（找周杰伦原版最实用 ✅）

**Base URL**：`https://tang.api.s01s.cn/music_open_api.php`
**协议**：免费开放，无需 Token，直接 GET；返回 JSON。
**亮点**：实测能拿到周杰伦《晴天》的 **m4a / PQ 926kbps FLAC / SQ 1647kbps FLAC** 播放直链（带 vkey 时效参数），uniq 级的无损音质。

### 3.1 第一步：按关键词搜索，拿 `song_mid`

```http
GET https://tang.api.s01s.cn/music_open_api.php?msg=周杰伦&type=json
```

实测返回（节选）：
```json
[
  {"song_title":"晴天","pay":"付费","song_mid":"0039MnYb0qxYhV","singer_name":"周杰伦"},
  {"song_title":"发如雪","pay":"付费","song_mid":"0027oMO61wWi55","singer_name":"周杰伦"},
  {"song_title":"兰亭序","pay":"付费","song_mid":"00128N3r2SYKMF","singer_name":"周杰伦"},
  {"song_title":"搁浅","pay":"付费","song_mid":"001Bbywq2gicae","singer_name":"周杰伦"},
  {"song_title":"七里香","pay":"付费","song_mid":"004Z8Ihr0JIu5s","singer_name":"周杰伦"}
]
```

### 3.2 第二步：按 `song_mid`（+歌名）拿详情和播放地址

```http
GET https://tang.api.s01s.cn/music_open_api.php?msg=晴天&mid=0039MnYb0qxYhV&type=json
```

实测返回字段（节选）：
| 字段 | 含义 |
|---|---|
| `song_name` / `song_title` | 歌名 |
| `album_name` | 专辑《叶惠美》 |
| `singer_name` / `singer_mid` | 歌手 / 歌手 MID |
| `song_play_url` | 标准音质 m4a 直链（193kbps） |
| `song_play_url_pq` | PQ 高品质 FLAC 直链（926kbps，29.72MB） |
| `song_play_url_sq` | SQ 无损 FLAC 直链（1647kbps，52.83MB） |
| `album_pic` / `singer_pic` | 专辑图 / 歌手图 |
| `duration` / `public_time` | 时长 / 发行日期 |

> 说明：返回的 vkey 直链**有时效性**，需要播放时重新请求一次拿新链接，不要长期缓存 URL。

## 4. Meting 系 API（APlayer / MetingJS 生态，最经典）

这类接口脱胎于著名的 Meting 项目，参数统一、无 Token 门槛，是开源音乐播放器最常见的接入方案。**搜索结果里直接带 `url`、`pic`、`lrc` 三个链接**，按需请求即可。

### 4.1 公共实例 A：api.injahow.cn（实测 ✅）

**Base URL**：`https://api.injahow.cn/meting/`
**开源项目**：https://github.com/injahow/meting-api （PHP，MIT）

| 参数 | 说明 |
|---|---|
| `server` | `netease`(默认) / `tencent` |
| `type` | `name` 歌曲名 / `artist` 歌手 / `url` 播放链接 / `pic` 封面 / `lrc` 歌词 / `song` 单曲 / `playlist` 歌单 |
| `id` | 对应类型的 ID（歌曲ID / 歌单ID / 封面ID） |

```http
GET https://api.injahow.cn/meting/?type=url&id=416892104       # 播放直链
GET https://api.injahow.cn/meting/?type=song&id=591321          # 单曲信息
GET https://api.injahow.cn/meting/?type=playlist&id=2619366284  # 歌单
GET https://api.injahow.cn/meting/?type=lrc&id=591321           # 歌词
GET https://api.injahow.cn/meting/?type=pic&id=109951170423411973  # 封面
```

### 4.2 公共实例 B：api.qijieya.cn（实测 ✅，支持 search）

**Base URL**：`https://api.qijieya.cn/meting/`

```http
# 搜索（这个实例支持 search，可直接搜"周杰伦"）
GET https://api.qijieya.cn/meting/?type=search&id=周杰伦&limit=10&server=netease

# 播放/封面/歌词
GET https://api.qijieya.cn/meting/?server=netease&type=url&id=210049
```

实测搜索"周杰伦"返回：布拉格广场、想你就写信(Live) 等，每条自带 `url`/`pic`/`lrc` 链接。

> ⚠️ 注意：`api.qijieya.cn` 的 `type=url` 实测返回空 body（可能限流或服务不稳定），但 `search` 正常。

### 4.3 MetingJS 前端集成（博客 BGM 神器）

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/aplayer/dist/APlayer.min.css">
<script src="https://cdn.jsdelivr.net/npm/aplayer/dist/APlayer.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/meting@2/dist/Meting.min.js"></script>
<div id="aplayer"></div>
<script>
  new Meting('aplayer').playlist({
    container: '#aplayer',
    id: '2619366284',       // 歌单 ID
    server: 'netease',
    type: 'playlist'
  });
</script>
```

## 5. 开源自建方案（长期稳定，推荐生产使用）

公共接口随时会挂，以下是 GitHub 上活跃维护的开源项目，自己部署后接口完全可控。

### 5.1 NeteaseCloudMusicApi Enhanced（网易云全接口）

- 仓库：https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced
- 部署：`docker run -d -p 3000:3000 binaryify/netease_cloud_music_api`
- 能力：搜索、歌单、歌词、扫码登录、每日推荐等全网最全网易云接口
- 用法示例：
  ```http
  GET http://localhost:3000/search?keywords=周杰伦&limit=10
  GET http://localhost:3000/song/url?id=5257138
  GET http://localhost:3000/lyric?id=5257138
  ```

### 5.2 OpenMusic-Meting-API（四平台聚合，功能最强）

- 仓库：https://github.com/qq01-hub/OpenMusic-Meting-API
- 平台：`netease` / `tencent` / `qishui`(汽水) / `kugou`
- 部署：
  ```bash
  docker run -d --name openmusic-meting-api -p 3000:3000 \
    --mount type=bind,source=/opt/meting-api/data,target=/app/data \
    w3126197382/meting-api:latest
  ```
- 统一接口：`GET /api?server=netease&type=search&id=周杰伦`
- `type` 支持：`song`/`playlist`、`search`/`search_playlist`、`fm`(私人漫游)、`url`/`lrc`/`pic`、`artist`、`dj` 系列
- 音质：`standard`/`exhigh`/`lossless`，平台专属如网易云 `hires`/`jymaster`、QQ `master`/`atmos`、酷狗 `viper_atmos` 等
- 特色：多账号 Cookie 管理、扫码登录、自动续期、管理后台（admin/admin123）、结构化逐字歌词
- ⚠️ 调用需要 API Token + 服务端短期签名（见仓库 docs/OPENMUSIC_AUTH.md）

### 5.3 KuGou API（酷狗，Yu9191/KuGou）

- 仓库：https://github.com/Yu9191/KuGou （Node.js 18+，MIT）
- 部署：`git clone → npm install → npm start`（默认 9191 端口），支持 Docker/PM2
- 接口：
  ```http
  GET /api/search?keyword=周杰伦&page=1
  GET /api/v5url?hash=<hash>&quality=high&fallback=1&mode=lite
  GET /api/lyric?hash=<hash>
  GET /api/audio_info?mixSongId=<id>
  ```
- ⚠️ 需抓包配置酷狗会员的 TOKEN/MID/USERID 等环境变量才能拿高音质，且约 1-2 天触发一次人机验证需重新配置。

## 7. 通用注意事项

1. **直链时效性**：QQ音乐/网易云的播放直链都带 vkey/sign，通常几小时失效，务必"用时再取"，不要缓存。
2. **User-Agent / Referer**：部分接口对请求头敏感，返回空时尝试加浏览器 UA。
3. **频率控制**：GD 明确要求 5 分钟 ≤50 次；Tang 和 Meting 公共实例请克制调用，避免被封。
4. **CORS**：纯前端直接调用可能遇到跨域，建议加一层后端代理（或用支持 JSONP 的接口）。
5. **接口失效是常态**：本文所有公共接口都可能随时变更，建议封装成统一适配层，方便切换后端。
